# Расширение OpenCart 4.x сервиса «Экспресс Платежи: ЕРИП»

Расширение CMS OpenCart для интеграции с сервисом «Экспресс Платежи». Расширение позволяет производить приём платежей через систему ЕРИП.

[Инструкция для установки и настройки](https://express-pay.by/extensions/opencart-4-x/erip)

[Наш Youtube канал с опубликованными видео по расширениям](https://www.youtube.com/c/express-pay-by)

## Описание

Расширение OpenCart добавляет платёжный метод «Экспресс Платежи: ЕРИП». При оформлении заказа клиент выбирает этот способ оплаты, его перенаправляют на платёжную страницу сервиса, после оплаты — возвращают обратно в магазин. Статус заказа обновляется автоматически по серверным уведомлениям от сервиса.

На странице успеха отображается инструкция по оплате через ЕРИП и (опционально) QR-код.

Расширение использует API v1 сервиса (`web_invoices`) и формирует цифровую подпись запросов (HMAC-SHA1).

## Возможности

- Приём платежей через ЕРИП через API v1 (`web_invoices`).
- Тестовый режим (Sandbox) с автозаполнением тестовых параметров.
- Формирование цифровой подписи (HMAC-SHA1) для подписи счетов.
- Приём серверных уведомлений о статусе заказа с проверкой подписи.
- Автоматическая смена статуса заказа.
- Отображение инструкции по оплате через ЕРИП на странице успеха.
- QR-код для оплаты (получение через API `qrcode/getqrcode`).
- Настройка пути в дереве ЕРИП.
- Разрешение изменять ФИО, сумму и адрес при оплате.
- Настройка текста описания заказа и сообщения об успешной оплате.

## Требования

- OpenCart 4.0.x;
- PHP 8.0 и выше;
- Исходящий доступ к API сервиса:
  - `https://api.express-pay.by/v1/` (production)
  - `https://sandbox-api.express-pay.by/v1/` (тестовый)

## Установка

### Шаг 1. Загрузка расширения

1. В админке OpenCart перейдите в **Модули / Расширения → Установка расширений**.
2. Нажмите кнопку **«Загрузить»** и выберите файл `expresspay_erip.ocmod.zip`.
3. Дождитесь окончания загрузки.
4. После добавления модуля в установленных расширениях нажмите **«Установить»**.

### Шаг 2. Установка модуля оплаты

1. Перейдите в **Модули / Расширения → Модули / Расширения**.
2. Выберите тип расширения — **Модули оплаты**.
3. В списке найдите «Экспресс платежи: ЕРИП» и нажмите **«Установить»**.

### Шаг 3. Настройка

1. Нажмите **«Редактировать»** напротив модуля.
2. Заполните настройки (см. раздел «Настройка»).
3. Нажмите **«Сохранить»**.

Проверка установки:

- Доступна страница настроек модуля.
- Расширение отображается в списке модулей оплаты со статусом «Включено».

## Настройка

Настройка выполняется в админке: **Модули / Расширения → Модули / Расширения → Редактировать**.

| Секретное слово для уведомлений | Ключ для проверки подписи уведомлений | `YOUR_NOTIFICATION_SECRET` |
| Адрес для получения уведомлений | URL для уведомлений (задаётся в личном кабинете ExpressPay) | *заполняется автоматически* |
| Показывать QR код для оплаты | Отображает QR-код на странице успеха | Да |
| Разрешено изменять ФИО | Клиент может изменить ФИО при оплате | Нет |
| Разрешено изменять сумму | Клиент может изменить сумму при оплате | Нет |
| Разрешено изменять адрес | Клиент может изменить адрес при оплате | Нет |
| Путь к ЕРИП | Путь по веткам ЕРИП для оплаты (показывается в инструкции) | `Интернет-магазины\Сервисы->...->Оплата заказа` |

| Сообщение при успешном создании счёта | Текст на странице успеха | `Номер вашего заказа: ##order_id##` |
| Статус | Включает/отключает метод оплаты | Включено |
| Порядок сортировки | Позиция в списке способов оплаты | `0` |

| Статус оплаченного заказа | Устанавливается при уведомлении «оплачен» | Оплачен |
| Статус заказа при ошибке | Устанавливается при ошибке/отмене | Отменён |

## Использование

1. Клиент оформляет заказ и выбирает «Экспресс платежи: ЕРИП».
2. Магазин формирует параметры счёта и подпись и перенаправляет клиента на оплату (`ReturnType=redirect`) на `.../web_invoices`.
3. После оплаты сервис возвращает клиента на страницу успеха магазина, где отображается инструкция по оплате через ЕРИП и (опционально) QR-код.
4. Серверное уведомление отправляется на URL из настроек (POST: `Data` + `Signature`).
5. Магазин проверяет подпись и изменяет статус заказа.

### Проверка в тестовом режиме

1. Включите «Использовать тестовый режим» — параметры подставятся автоматически.
2. Оформите заказ и оплатите через sandbox-сценарий сервиса.
3. Проверьте статус заказа в админке.
